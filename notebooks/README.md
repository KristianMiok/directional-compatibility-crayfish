# Notebooks

Disposable, exploratory work — **not part of the pipeline**.

Naming convention: `YYYY-MM-DD_initials_short-description.ipynb`
e.g. `2026-04-21_km_sanity-check-snap-distance.ipynb`

When something proves useful, promote it into `src/dcc/` as a function
and call it from a script in `scripts/`.

Notebooks should not be the source of any output that ends up in the
manuscript or the Stage report.
