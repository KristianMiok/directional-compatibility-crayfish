# Supplementary files

Public supplementary outputs for the manuscript
**"Directional ecological asymmetry in a globally distributed,
network-constrained freshwater taxon."**

## Per-species network metrics

`species_directed_network_metrics.csv` — directed network metrics for each
species in the analysed cohort (155 rows).

## Metric audit (five metrics)

The Appendix reports the metric-agreement audit over four directional
compatibility metrics. The files below give the complete matrices including a
fifth metric, `quantile_90_suitability`, whose values are referenced in the
main text. The four-metric block is identical to the Appendix tables.

| File | Appendix table (4x4) | Content |
|---|---|---|
| `metric_audit_5x5_donor_top20_overlap.csv` | S13 | Overlap in each species' top-20 outgoing partners between metric pairs |
| `metric_audit_5x5_acceptor_top20_overlap.csv` | S14 | Overlap in each species' top-20 incoming partners between metric pairs |
| `metric_audit_5x5_spearman_outgoing.csv` | S15 | Spearman correlation between metrics, outgoing (donor) direction |
| `metric_audit_5x5_spearman_incoming.csv` | S16 | Spearman correlation between metrics, incoming (acceptor) direction |
| `metric_audit_5x5_summary.json` | — | Run parameters and off-diagonal summary statistics |

Metrics: `mean_suitability`, `fraction_above`, `directional_schoeners_d`,
`directional_warrens_i`, `quantile_90_suitability`.

Source matrix: the primary `full_geofresh` / GBM compatibility matrix
(155 species). Top-20 overlap uses n = 20.

Generated by `scripts/84_stage5_metric_sensitivity_q90.py`.
